# M88amを参考にした互換性修正

参照元は [M88am 2026/09-01の公開ソース](https://www.ambientworks.jp/_site/download/M88am-202609-01.zip)
の `CHANGES.md` §2および同梱ソース。追加コードの著作権表記は `LICENSE` に記載する。
M88Vで問題を再現できた箇所を個別に修正し、CPUコア全体の置き換えは行わない。

## 検証対象

- Z80命令のクロック数とAFの復元。命令時間の期待値は
  [Zilog Z80 CPU User Manual](https://www.zilog.com/docs/z80/um0080.pdf)を基準にする。
- YM2608 ADPCMの繰り返し再生時の終端通知。
- CRTCの属性なし表示での画面反転と、文字属性との反転の組み合わせ。

既存のCCF、メモリウェイト有効化は対応済みのため変更しない。
ADPCMの外部RAM開始アドレスについても、M88Vは既に設定しているため今回の変更に含めない。
VRTC・600Hzタイマーの精度改善とADD16の保持フラグ修正については
[CRTC_TIMING-ja.md](CRTC_TIMING-ja.md)を参照。

## 取り込んだ修正と再現結果

### CPU

`z80_observer_test` に752チェックを追加し、修正前は476チェック失敗、修正後は全成功。
命令時間はウェイトなしで検証し、既存の `z80_wait_test` でウェイト加算も確認した。

- DJNZ: 不成立8／成立13 T、RET: 10 T、条件付きRET: 不成立5／成立11 T、RST: 11 T。
- HLの絶対アドレス転送: 16 T、IX/IY版: 20 T。
- 即値メモリ転送: `(HL)` は10 T、`(IX/IY+d)` は19 T。
- インデックス付きメモリアクセスのプレフィックス4 Tの二重加算を除去。
  INC/DECの23 Tへの修正はM88amにも残っていた不整合を仕様に基づき修正したもの。
- POP AF／EX AFの全256フラグ値の保持と、リセット時の内部フラグ初期化。

### ADPCM

リピート終端でもEOSを通知し、再生自体は継続する。
`adpcm_repeat_test` は修正前37チェック失敗、修正後全成功。
1bit/8bitメモリ設定、終端直前・直後、7周のフラグ検出と解除、IRQ、マスク、
明示停止、公開ミキサー経路を検証した。特定の市販ソフトの動作確認ではない。

### CRTC

全画面反転を内部の属性ラッチに混ぜず、展開時に適用する。
`crtc_inverse_test` は修正前に属性なしモードの反転で失敗、修正後は20通りすべて成功。
合成フォントの期待画素を使い、40/80桁、カラー/モノクロ、属性形式、
文字単位の反転との組み合わせ、反転ON/OFFを検証する。

旧式デバイス状態rev1/2は保存時・復元時に属性表現を変換してレイアウトを維持する。
この修正時点では精密チェックポイントを形式2へ更新した。
現在はFM・ADPCM・リズム音源の内部状態を含む形式5を使うため、形式1〜4は再作成が必要。

## 統合検証

- GUI・ヘッドレスをビルドし、全19 CTest成功。
- 許可済み実ROMのN／N88V1／N88V1H／N88V2で、保存・復元、継続実行、
  計測ON/OFFの同一性、リプレイ、破損拒否、別プロセス復元が成功。
- ネイティブ描画の実ROMテストは4MHz・8MHzともBASICのバナーとOkを確認。
  拡大フィルター切替、ワーカー停止・再開・終了も成功（非表示ウィンドウ、音声デバイスなし）。
