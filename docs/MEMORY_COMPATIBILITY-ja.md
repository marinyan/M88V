# メモリ互換性の修正

## PC-8001mkIIの40H出力bit 4（2026-09-23）

[PC-8001mkII解析マニュアルII・183ページ](https://archive.org/details/pc-8001mk-ii-ii_202108/page/183/mode/2up)では、40H出力bit 4は未使用とされている。182ページの入力bit 4（カレンダのCDI）とは別の信号である。

M88Vには `Memory::Out40` にGVRAMウェイト切替処理があり、従来はN802にも適用されていた。ただし通常のI/O接続表にはこのハンドラが接続されておらず、通常のOUTで発現する不具合とは確認されていない。旧形式のメモリ状態復元はこのハンドラを直接呼び、チェックポイントはウェイト種別自体を復元するため、保存状態にbit 4や対応するウェイト種別が含まれると影響する潜在バグだった。

N802ではウェイト適用時に、GVRAM選択状態から通常のウェイト種別を再計算する。これにより旧形式の状態復元、チェックポイント復元、その後のバンク切替とVRTC更新で未使用ビットの効果が残らない。状態ファイルの形式と保存するポート値は維持する。PC-88系とN80V2（SR）の既存ポリシーは変更しない。通常OUTへのハンドラ追加も行わない。

`memory_port40_test` は合成ROMでコアを初期化し、bit 4を設定したメモリ状態と従来の高速ウェイト種別を含むチェックポイントを復元する。4MHz・8MHz、表示期間・垂直帰線期間、GVRAMバンク再選択とVRTC更新を検査する。修正前は12項目失敗し、修正後は成功。PC-88の既存ウェイト切替を維持する検査も含む。実機での絶対ウェイト数を測定したものではない。
