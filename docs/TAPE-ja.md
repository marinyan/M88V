# テープ操作と CMT 出力

Windows GUI の `Tape` メニューで操作します。

| 操作 | 内容 |
| --- | --- |
| Open | 再生する T88 を開き、先頭へ移動 |
| New empty T88 | 空の T88 を作成し、再生側にセット |
| Rewind | セット中のテープを先頭へ戻す |
| Go to end | セット中のテープの末尾へ移動 |
| Eject | 再生テープを取り外す |
| Save recording as | エミュレート中の CMT 出力を T88 または CMT に保存 |
| Clear recording | 確認後、録音バッファを消去 |

X88000 と同様、**再生テープと録音バッファは別**です。BASIC の `CSAVE` や
機械語の USART 送信は、CMT チャンネル・モーター ON・送信許可のとき自動的に録音します。
再生用 T88 を開かなくても録音できます。セット中のファイルに自動上書きはしません。

録音例：

1. 前の録音が不要なら `Clear recording` を選ぶ。
2. エミュレータ内で BASIC の `CSAVE` などを実行する。
3. 出力が終わったら `Save recording as` で保存する。
4. 読み戻すときは保存した T88 を `Open` で開く。再度読む場合は `Rewind` を選ぶ。

保存後も録音バッファは残り、続く出力は末尾に追加されます。`New empty T88`、
`Open`、`Eject`、`Rewind` は録音バッファを消去しません。
未保存録音がある状態で GUI を終了すると、保存・破棄・終了キャンセルを選べます。
保存のキャンセルや失敗でも録音データを保持します。

T88 はヘッダー、バージョン、終端タグを持つ形式で、空ファイルは 34 バイトです。
録音では 600／1200 baud、USART のデータ形式、マーク／スペースのキャリアを記録します。
CMT 保存はデータバイトだけを書き出すため、キャリアや速度情報は含みません。
再生入力は従来どおり T88 です。CMT の直接読み込みには対応していません。
これはデジタルのテープイメージ入出力であり、音声波形の録音ではありません。

## ローカル HTTP API

既存 API と同じトークン認証を使います。すべて POST です。

| パス | クエリ | 内容 |
| --- | --- | --- |
| `/v1/tape/open` | `path` | T88 をセット |
| `/v1/tape/create` | `path` | 空の T88 を作成（セットは別途 open） |
| `/v1/tape/rewind` | なし | 先頭へ移動 |
| `/v1/tape/end` | なし | 末尾へ移動 |
| `/v1/tape/close` | なし | 取り外し |
| `/v1/tape/save` | `path`, `format=t88` または `cmt` | 録音を保存（既定 T88） |
| `/v1/tape/clear-recording` | なし | 録音を消去 |

API の create/save は指定した出力ファイルを置き換えます。録音はメモリ上に保持されるので、
headless の終了前に save を実行してください。
入力記録中はテープ操作を受け付けません。開発用チェックポイントの保存・復元には、
テープの取り外しと録音バッファの消去、CMT 送信の停止が必要です。
録音状態を追加したため、この変更前の開発用チェックポイントとは互換性がありません。

## 参考と検証

作者公開の [X88000 1.5.3 ソース](https://quagma.sakura.ne.jp/manuke/x88src.html)
の `TapeImage.h/.cpp`、`PC88Usart.h`、`PC88Z80Main.cpp`、`X88TapeImageDlg.cpp` を参照しました。
作者はこのソースを PDS としています。M88V での追加部分は BSD-2-Clause、既存コアの条件は維持します。

`tape_test` は ROM 不要で、USART 録音、T88 の再生、CMT バイト列、空 T88、タグ分割、
巻き戻し・末尾移動・モーター停止、不完全な入力、保存失敗時の保持を検証します。
実機 ROM を使った BASIC の CSAVE/CLOAD と GUI の対話操作は別途確認が必要です。
