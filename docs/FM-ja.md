# FM音源の選択

M88Vは、設定した音源の種類に応じてymfmのYM2203（OPN）またはYM2608（OPNA）のFMエンジンを使う。FMの生成に外部ROMは不要。

Windows版のオプション「音」にある本体側「FM音源 (44h)」と増設側「FM音源 (A8h)」で個別に選択する。設定の反映にはエミュレータのリセットが必要。GUIとヘッドレスで同じコアを使用する。

| 設定 | FMコアと発音 | I/O |
|---|---|---|
| 本体 OPN | YM2203、FM 3音、モノラル | 44H/45H |
| 本体 OPNA | YM2608、FM最大6音、ステレオ、リズム・ADPCM-B | 44H〜47H |
| 増設 OPN（PC-8801-11相当） | 独立したYM2203 | A8H/A9H |
| 増設 OPNA（PC-8801-23相当） | 独立したYM2608 | A8H/A9H、ACH/ADH |
| 増設なし | 増設音源を無効化 | 読み出しはFFH |

本体OPN＋増設OPNA、OPN＋OPNなどの既存設定を維持する。表はM88Vの設定であり、全実機への物理的な装着可否を保証するものではない。PC-8801-11の[資料](https://vuj.sakura.ne.jp/pc88/88_11.html)には、SR/TR/FR/MR/FH/MHで内蔵FMと合わせた6音演奏が可能、PC-8801-23/-24との併用は不可とある。

## 実装と互換性

- FMは3チャンネルのOPN用と6チャンネルのOPNA用エンジンを生成し分ける。YM2203では拡張バンク・LFO・リズムを受け付けず、YM2608では29Hの3音/6音切り替えと左右定位を反映する。
- 外部音源クロックは通常YM2203が3.9936MHz、YM2608が7.9872MHz。CPUの4/8MHz切り替えで音程を変えない。各音源の分周設定と出力レートへの変換位相を独立に保持する。
- YM2203の浮動小数点DAC変換とYM2608の出力ビット幅はymfmのチップ実装に合わせる。FM音量設定・チャンネルミュートを維持し、ミュート中もエンベロープとフィードバックは進む。
- SSG、ADPCM-B、CPU時間で進むタイマー・割り込みは既存のfmgen/M88処理を使用する。タイマーAのCSM発音を新しいFMエンジンへ通知する。今回の変更はFM合成の更新であり、チップ全体のバス動作やアナログ回路の完全な再現ではない。
- リズムは前回追加したADPCM-A ROM方式（ROM不在時はWAV）を維持する。
- 精密チェックポイントは形式5。FMの位相・エンベロープ・フィードバック・LFO・変換途中のサンプルを保存する。形式1〜4と、それらを含むリプレイは再作成が必要。旧M88状態ファイルは従来のレジスタ復元方式のまま。

## 検証

`opn_fm_test` は固定版ymfmの完全なYM2203/YM2608チップを参照として、8アルゴリズム、3分周、5種類のSSG-EG設定、LFO、チャンネル3特殊モード、キーオフのFM出力を比較する。さらに音数・モノラル/ステレオ・音量・ミュート中の進行・CSM・不正状態拒否・8/44.1/48/96kHzでの保存復元と分割描画を検証する。

`adpcm_state_test` は4/8MHzそれぞれで本体・増設音源の設定を切り替え、実際のPC88スケジューラを通したタイマー状態とFM出力がチェックポイント復元後に一致することを確認する。ADPCM-B・ROMリズムの既存検証も継続する。

参照元は[ymfm固定版](https://github.com/aaronsgiles/ymfm/tree/81aec25ccbb98f4873a255f7551ac4dadac59b4a)。実機録音との聴感比較、基板ごとのアナログ音量比・フィルタ特性の検証は未実施。
